# 🍽️EpicEats🍽️
EpicEats is a modern and dynamic food ordering web application that brings together a variety of delicious food items into a seamless digital dining experience. Whether you're craving fast food, fine dining, or a home-style meal — EpicEats has it all.

"Good food is the foundation of genuine happiness." – Auguste Escoffier

- 🚀 Features at a Glance
- 🛍️ Food ordering system with shopping cart

- 🍽️ Menu browsing with advanced filtering

- 🗓️ Table booking functionality

- 🧾 Checkout with order summary and payment integration

- 🌙 Dark mode toggle

- 🔐 Login and Sign-Up system

- ⚡ Smooth UI interactions with hover effects and animations

- 🐞 Bug fixes and performance improvements
